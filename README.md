#  Тетрис - Консольная игра на C++

Это реализация игры **Тетрис** для терминала Linux/Unix.

![Demo](animation.gif)

## Особенности
+ Цветная графика
+ Настраиваемое управление
+ Система рекордов
+ Режим паузы
+ Разные режимы

## Режимы игры 
+ Классический Тетрис
+ Тетрис в форме ведра
+ Режим "Собери картинку"
### Режимы последовательности фигур:
Игра поддерживает числовой аргумент для установки начального числа с которого начинается генерация случайных чисел. Это позволяет воспроизводить одинаковую последовательность фигур при разных запусках.

## Управление

### Стандартные клавиши:

Основные клавиши:
+ A или стрелка влево - двигать фигуру влево
+ D или стрелка вправо - двигать фигуру вправо
+ S или стрелка вниз - ускорить падение
+ W или стрелка вверх - мгновенно сбросить фигуру
+ Пробел - повернуть фигуру
+ E - пауза/продолжить
+ Q - выход из игры

Все клавиши можно перенастроить в меню настроек

## Установка

### Шаги установки:

```basht
git clone https://github.com/Olesya077/TETRIS
cd TETRIS
mkdir build
cd build
cmake ..
make
```

## Запуск

```bash
# Без аргументов
./tetris_game

# С числовым аргументом 
./tetris_game 42

```
